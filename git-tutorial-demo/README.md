# Git Graph Tutorial — Demo Branches & Modules

This directory provides clean, modular files and features designed specifically for demonstrating Git branching, commits, fast-forward merges, 3-way merge commits, and interactive rebasing to students.

## Available Demo Modules:
- `auth-validator.ts` — Email/password validation logic.
- `analytics-service.ts` — Categorized event tracking.
- `api-client.ts` — HTTP client with auto-retry mechanism.
- `notification-badge.tsx` — React notification counter component.
- `theme-context.tsx` — Light/Dark theme provider context.
- `date-formatter.ts` — Relative and locale date formatters.
- `modal-dialog.tsx` — Accessible React modal component.
- `cache-manager.ts` — TTL in-memory cache manager.
- `rate-limiter.ts` — Token bucket rate limiting algorithm.
- `STUDENT_GIT_MERGE_REBASE_GUIDE.md` — Complete reference guide for lecture walkthroughs.
